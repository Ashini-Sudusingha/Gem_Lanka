# 💎 Gem Lanka — Unified System Repository

Welcome to the unified repository for the **JEM Lanka** gemstone marketplace platform. This repository contains both the premium frontend interface and the enterprise Java EE backend engine.

---

## 📁 Repository Structure

*   **`jemLanka/`**: The complete frontend application built using static HTML5, Tailwind CSS v4, Alpine.js, and Vanilla JavaScript.
    *   👉 For details on features, components, bug fixes, system screenshots, and the **React migration plan**, see the [Frontend README](jemLanka/README.md).
*   **`JemLankaBackEnd/`**: The secure Java EE servlet engine utilizing Hibernate 5 ORM, GSON, and MySQL.
    *   👉 For details on Java controllers, database entities, and mail configurations, see the [Backend README](JemLankaBackEnd/README.md).

---

## 🚀 Overview

JEM Lanka is a high-end online marketplace designed to showcase and sell natural Sri Lankan gemstones. It integrates user authentication, advanced gemstone cataloging and relational search filters, dynamic shopping carts, and administrator dashboards to monitor purchases, deliveries, and inventory.
